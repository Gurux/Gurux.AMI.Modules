# Scalar API view

Open `/scalar/v1` to browse the API. Choose an operation to inspect its parameters, request body and response types.

Fill in the required values and authentication before sending a request. Sending a request executes the selected AMI operation with the supplied permissions.

If the document cannot be loaded, check that the OpenAPI module is enabled and `/openapi/v1.json` is available. If an operation is denied, check the signed-in user's permissions or the authentication supplied with the request.
