# OpenAPI module

The OpenAPI module describes the HTTP endpoints currently available in AMI. The document is available at `/openapi/v1.json` while the module is enabled.

Use the document with integration tools and API clients. Swagger and Scalar use this document to provide interactive API views. Enable OpenAPI before enabling either of those modules.

This module has no configuration form or interactive view of its own. API authorization is still enforced by the endpoint being called.
