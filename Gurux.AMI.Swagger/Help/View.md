# Swagger API view

Open `/swagger` and expand an operation to inspect its parameters and response schema. Use Try it out, enter the requested values and select Execute to send the request.

Execution calls the AMI operation with the authentication and permissions supplied by the current session or request.

If the API list is empty or the document cannot be loaded, check that OpenAPI is enabled and `/openapi/v1.json` is available. Review the response status and body when an operation fails.
