# SMTP configuration

Set the SMTP server address and port, sender email address and password. Enable Use TLS (STARTTLS) when required by the mail server. Timeout is measured in seconds and must be between 1 and 300.

Use the AMI Save action to persist changes. A saved password is not displayed again; leave the password field unchanged to keep it.

Enter a receiver in Test email and select Send test email to test the current form values. A successful test does not save the form. Review the reported error if the server rejects the connection, authentication or receiver.
